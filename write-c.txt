===== NFA->DFA->Minimization Demo =====

========= 正规式→NFA→DFA→最小化演示 =========

1. PL/0标识符正规式: letter(letter|digit)*
   等价于: [a-zA-Z]([a-zA-Z]|[0-9])*

   构造NFA: 4个状态, 起始状态: q0, 接受状态: q0

2. NFA→DFA (子集构造法):
   ε-closure(q0) = {q0}
   move({q0}, letter) = ε-closure({q1}) = {q1, q2, q3}
   标记新状态 D0 = {q0}
   D1 = {q1, q2, q3} = move(D0, letter)
   D2 = {q2, q3} = move(D1, letter)
   D1 = move(D1, digit) = D1 (自环)

3. DFA最小化(Hopcroft算法):
   初始划分: {非接受状态}, {接受状态}
   检查每个组的不可区分性...
   最终划分: {D0}, {D1}, {D2}
   D0 --letter--> D1
   D1 --letter--> D2
   D1 --digit-->  D1
   D2 --letter--> D2
   D2 --digit-->  D2

4. PL/0数字正规式: digit+
   NFA: q0 --D--> q1 --D--> q1 (循环)
   DFA: 同上，直接就是最小DFA
   q0 --digit--> q1 --digit--> q1
